# nancygao.com

Personal website of Dr Nan Gao, Associate Professor at the College of Software, Nankai University.

Live site: https://nancygao.com

## About

A single-page bilingual (English / Chinese) academic homepage, built as plain HTML and hosted on GitHub Pages. No build step or framework is required.

## Structure

- `index.html`: all page content and styles
- `assets/cats/`: section illustrations
- `assets/research/`: research overview images
- `wp-content/uploads/`: paper PDFs and images (original paths kept so that existing links remain valid)

## Updating

- Text is written in pairs: `<span class="en">English</span><span class="zh">中文</span>`.
- To add a news item or paper, copy an existing `<li>…</li>` block in the relevant section and edit it.
- Changes go live within a few minutes of committing.
